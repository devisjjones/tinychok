# Тайничок

Отдельный репозиторий под атмосферный messenger MVP.

## Что уже есть

- отдельный git-репозиторий в `/Users/devisjones/Documents/New project/tinychok`
- `React + TypeScript + Vite`
- стартовый экран мессенджера: список диалогов, активный чат, composer, фильтры и локальная отправка сообщений

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
