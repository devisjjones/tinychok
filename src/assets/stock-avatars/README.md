Папки со стоковыми аватарками для popup-выбора.

- `channels/` — стоковые аватарки каналов
- `users/` — стоковые аватарки пользователей

Что можно класть:

- `png`
- `jpg`
- `jpeg`

Как это работает:

- popup автоматически подхватывает все изображения из соответствующей папки
- подпись в списке строится из имени файла
- после добавления новых файлов нужен новый frontend build
